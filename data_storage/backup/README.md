## Task 1


1.1. Восстановление данных в полном объеме за предыдущий день

Для этого случая Full Backup, который делается по расписанию раз в сутки — например, глубокой ночью (в 2–3 часа утра), когда нагрузка на финансовую систему минимальна.

Каждую ночь скрипт полностью копирует всю базу данных целиком в архив и складывает на отдельный сервер бэкапов. Если в течение дня что-то ломается, мы просто берем ночной архив и раскатываем его обратно.

Минус: Теряются все транзакции и действия пользователей, которые произошли с момента ночного бэкапа до момента аварии. Но по условию задачи (вернуть состояние на вчера) этого решения достаточно.

1.2. Восстановление данных за час до предполагаемой поломки

Используют комбинацию: полный бэкап + бэкап инкрементов (или журналов транзакций).

Раз в сутки (ночью) мы делаем один большой Full Backup. А затем каждый час запускаем Incremental Backup (копируем только то, что изменилось за этот конкретный час) или непрерывно сохраняем WAL-логи (Write-Ahead Logs в PostgreSQL / бинарные логи в MySQL), где записано вообще каждое действие с базой.

Как восстанавливаем: Если база упала, например, в 16:40, мы сначала восстанавливаем ночной полный бэкап, а сверху поочередно накатываем часовые кусочки вплоть до 15:00 или 16:00. В итоге база вернется в рабочее состояние с минимальными потерями данных.

## Task 2

В PostgreSQL для этого используются стандартные консольные утилиты pg_dump (для создания копии) и pg_restore (для ее разворачивания).
Создание бэкапа (Резервирование)
Чтобы сделать бэкап, лучше всего использовать кастомный сжатый формат (-F c), так как он весит меньше всего, и его потом можно разворачивать выборочно или в несколько потоков.

```
pg_dump -h localhost -U my_user -F c -b -v -f "/backups/my_db_backup.dump" my_database_name
```

Восстановление базы данных
Если база упала или мы переносим её на другой сервер, используем pg_restore.

```
pg_restore -h localhost -U my_user -d my_database_name -v "/backups/my_db_backup.dump"
```

## Task 3

Делаем  Full Backup:

```
xtrabackup --backup --target-dir=/backups/mysql/base_full --user=root --password=pass
```

Эта команда создает полную копию данных в папке /base_full.
```
xtrabackup --backup \
  --target-dir=/backups/mysql/inc_1 \
  --incremental-basedir=/backups/mysql/base_full \
  --user=root --password=pass
```
