## Task 1

Проблемы, которые может решить кэширование:

1. Медленный отклик. Чтение данных с жестких дисков происходит достатолчно медленно, по сравнению с получением данных из кэша, которые хранятся в оперативной памяти. 
2. Проблема высоких нагрузок на базы данных при большом потоке запросов.
3. Пробема плохой масштабируемости при пиковых нагрузкахю
4. Проблема избыточности вычислений. Результаты вычислений можно кэшировать, что значительно снижает нагрузку.
